SECTION 4 - INSTALL-ONLY APP

Only local appearance settings are loaded. Install events are captured before React renders. The old dismissible iOS banner was removed from App.tsx.
web/vite.config.ts: production gate is always on and rejects VITE_INSTALL_GATE=off. Emulator dev/builds skip it by default; VITE_INSTALL_GATE=on enables gate tests. No query/storage bypass exists. Manifest id=/, start_url=/map, scope=/, standalone display/display_override, portrait. The existing production-emulator safety guard remains.
web/index.html: zoom-limited viewport, light/dark theme-color metas, Apple/mobile capable, black-translucent status bar and launch-image links. web/tools/generate-splash.py creates 16 images from the existing icon: light/dark at 375x812@3, 390x844@3, 393x852@3, 402x874@3, 420x912@3, 430x932@3, 440x956@3, 414x896@2. Total 392,504 bytes, well below 1.5 MB.
Choices: recognized in-app brands and generic Mobile WebKit UAs lacking Safari/CriOS/FxiOS/EdgiOS/OPiOS markers receive the Safari handoff. Other unrecognized iOS browser UAs use the Safari-style instructions. In-app detection is necessarily heuristic; a website cannot inspect a browser's native Share menu. Android deep links remain within manifest scope. iPhone home-screen launch starts at /map, as the brief permits. Desktop F11/fullscreen follows the brief's installed definition. An appinstalled event alone displays the launch instruction; it does not unlock a normal tab.

SECTION 5 - APP BEHAVIOR
web/src/platform/appFeel.ts and appFeel.css, main.tsx, theme.css: fixed-height shell with internal scrolling; hidden scrollbars, no body/page scroll, no selection except editable fields, no image dragging or link/image callouts, no default context menu outside fields, touch tap highlights removed, keyboard-only focus outlines, hover effects restricted to fine hover pointers.
Page gesture zoom, desktop modifier wheel and +/-/0 are suppressed. Every form control computes to at least 16px. Map gestures and photo zoom stay active. PhotoViewer.tsx also fixes an actual pinch bug: capture the ratio before React's deferred state update, so pointer-up cannot reset its denominator and force maximum zoom.
WebKit in this installed Playwright build has no overscroll-behavior support (CSS.supports=false and empty computed values). CSS declares none for html/body, while the fixed frame and touch-edge prevention also stop overscroll on that engine. Tests exercise the fallback, not a falsely claimed computed property.
App.tsx uses leading-edge swipe-back (20px start, left English/right Arabic); content follows the finger, with a 90px/25% completion threshold. Root tabs, editable fields, open dialogs and map/photo gesture targets are excluded. Back still uses browser history. Internal anchors remain in-window; external HTTP links use an outside window with noopener/noreferrer; phone/mail/application links retain their system handlers. Android message UI has no text-selection/copy handler to port; editable fields retain native selection.
platform/updates.ts centralizes registration/update state, shared by App's existing in-app update banner and Settings -> About -> Check for updates. The title remains CatMap Dubai in both languages. Safe-area variables resolve to env(safe-area-inset-top/bottom); top bars and bottom navigation honor them.
