# CatMap Web (iPhone and browsers)

The web version of CatMap Dubai, for iPhone users. People open it in Safari and add it to the home screen, where it
works like an app. It's a close copy of the Android app in `../app`. It uses the same Firebase project (the same
accounts, posts and photos), the same security rules (`../firestore.rules`) and the same text in both languages
(`../tools/strings`).

**Status:** not built yet. The full build brief is in `../CLAUDE_TO_CODEX.txt`.
