# Android screen implementation reference

Research source: `app/src/main/java/com/catmap/dubai/ui/**`, `MainActivity.kt`, and the enum/settings/limit definitions used by those screens. This is an implementation checklist, not a redesign. Values are Android dp unless stated otherwise. Use the existing resource strings, including Arabic, rather than recreating copy. The source-key inventory below lists every referenced string per UI source file.

## Shell, theme, roles, and navigation

- `MainActivity.kt`: edge-to-edge transparent system bars; theme follows `AppSettings.theme`; large text scales the current font scale by **1.18**. If Firebase is unavailable, show SetupRequiredScreen. Notification permission is requested once on Android 13+. UpdatePrompt is available on every screen. Post deep links resolve to `post/{id}`; notification route is deferred until the account is verified.
- `navigation/AppNavHost.kt`, `Routes.kt`: initial route is **login** without a user, **verify** for unverified email, otherwise **map**. Signing out/deleting resets to login. `help-directory` is deliberately public and included in `authRoutes`; offline banner is suppressed on auth routes. Persistent background errors appear as snackbar; listener errors get an error-container strip with **try_again**.
- Bottom navigation is shown only on map/explore/messages/profile: **Map · Explore · (+) · Messages · Profile**, 68dp high plus navigation safe area, 6dp horizontal padding. Tabs share equal width; active icon scales1.12; tab container radius18, active highlight pill padding16h/4v. Center post button52 circle with gradient, add icon32, shadow2. Message badge caps at99+. Bell also caps99+ and exposes `unread_notifications` plural accessibility label.
- Forward screens slide one-quarter width over320ms plus260ms fade; exits one-eighth width/fade200ms. RTL reverses direction. Tabs crossfade220/160ms. New post enters vertically380ms plus300ms fade.
- Role predicates from `data/model/Enums.kt`: volunteer = volunteer/moderator/admin; moderator = moderator/admin; admin = admin only. Route graph itself does **not** reject unauthorized admin/edit URLs; buttons are conditionally exposed, with repository/Firestore rules enforcing authorization. Web must protect those routes and mutations too.
- Shared `theme/Theme.kt`: shape radii **8/12/18/24/32**; brand gradient **#FF7A45 → #E5486B → #8E5CF7**. Light primary#A9531A/primaryContainer#FFDBC8, secondary#00696B/secondaryContainer#9CF1F2, tertiary#7A5900/tertiaryContainer#FFDEA3, error#BA1A1A, background/surface#FFFBF7, onSurface#221A15, variant#F4DED3, onVariant#52443C, container#F8EDE6/high#F2E6DF/low#FCF2EC, outline#85746B. Dark primary#FFB68D/container#7D2E00, secondary#80D4D5/container#004F50, tertiary#F2BF48/container#5C4200, background/surface#1A1410, onSurface#F0DFD7, variant#52443C, onVariant#D7C2B8, container#271F1A/high#322924/low#221A15, outline#A08D84.
- Typography preserves Material3 defaults; display/headlineLarge/headlineMedium bold, headlineSmall/titleLarge/titleMedium/labelLarge semibold. User-entered body text chooses direction from its content.

## Source-parity discrepancies to handle deliberately

- Preset post category starts Photos, not Details; chooser excludes Spotted/Other while full Type step includes them.
- Map All does not include sitters; only selected Sitting does. Stations are visible only under empty layer selection. Main map does not plot separate rescue reports.
- Microchip filter is functional but omitted from extraCount/isEmpty; older/stale/closed behavior belongs to posts, not community cat markers.
- Android guards edit/admin entry actions but navigation itself lacks role rejection; preserve UI gates and add secure URL/mutation gates on web.
- Optional video copy says30seconds but Android only checks MIME and30MiB size. Web may enforce the stated duration as a deliberate improvement.
- Several edit/poster routes retain a spinner when the source document is missing; use explicit missing states on web to prevent an unusable screen.
